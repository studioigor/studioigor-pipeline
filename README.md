# Не делай игру. Настрой пайплайн.

Презентация со стрима от автора youtube-канала [studioigor](https://youtube.com/@studioigor) — геймдев с нейросетями.

**▶ Запись стрима:** https://youtube.com/live/C3XLKksF4oc
**▶ Смотреть презентацию:** https://studioigor.github.io/studioigor-pipeline/

Как держать нейросеть под контролем на каждом этапе — от концепта до релиза — и строить инструменты, чтобы вы с ней видели одну и ту же игру. 46 слайдов, 10 этапов: идея, стиль, движок, окружение, ассеты, механики, вертикальный срез, контент, полировка, релиз.

## Управление

| Клавиша | Действие |
|---|---|
| `→` `↓` `Пробел` `PageDown` / клик по слайду | следующий слайд |
| `←` `↑` `PageUp` / клик по левой трети слайда | предыдущий слайд |
| `Home` / `End` | первый / последний слайд |
| номер + `Enter` | перейти к слайду |
| `F` | полный экран |
| `T` | светлая / тёмная тема |

На конкретный слайд можно дать ссылку через номер в адресе: `…/studioigor-pipeline/#12`.

## Локальный просмотр

```sh
python3 -m http.server 8000
```

и открыть http://localhost:8000. Шрифты загружаются с Google Fonts, поэтому нужен интернет.

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`. Файл `.nojekyll` отключает обработку Jekyll, страница отдаётся как есть.
